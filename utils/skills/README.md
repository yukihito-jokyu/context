# 共通 Skill

`utils/skills/` は、複数プロジェクトで再利用する Skill の正本です。各 Skill の詳細な手順は対応する `SKILL.md` を参照してください。

| Skill | 概要 |
|---|---|
| [archify-jp](archify-jp/SKILL.md) | 自然言語または Mermaid から、検証済みのインタラクティブ HTML 図を生成する。 |
| [blindspot](blindspot/SKILL.md) | 作業前に未知や見落としやすい論点を洗い出す。 |
| [commit](commit/SKILL.md) | 変更を確認してコミットする。 |
| [explanation-design](explanation-design/SKILL.md) | 読者が理解に到達できる説明構成を設計する。 |
| [grill-issue](grill-issue/SKILL.md) | Issue を精査し、議論を経て実装計画を立てる。 |
| [html-requirements-workshop](html-requirements-workshop/SKILL.md) | HTML モックを反復しながら曖昧な画面要件を固める。 |
| [interview](interview/SKILL.md) | 曖昧な点や既知の未知を一問ずつ明確にする。 |
| [my-skill-creator](my-skill-creator/SKILL.md) | Skill の作成、改善、評価、最適化を行う。 |
| [notes](notes/SKILL.md) | 実装中の判断、逸脱、エッジケースを記録する。 |
| [pitch](pitch/SKILL.md) | 実装の背景、変更、判断理由、レビュー観点を説明資料にまとめる。 |
| [plan](plan/SKILL.md) | 重要判断を明示したレビュー可能な実装計画を作る。 |
| [pr](pr/SKILL.md) | Pull Request を作成する。 |
| [prototype](prototype/SKILL.md) | UI や成果物を軽量に可視化して判断基準を引き出す。 |
| [quiz](quiz/SKILL.md) | AI 生成物や変更内容への理解漏れを確認する。 |
| [reference](reference/SKILL.md) | 既存成果物から仕様、命名、設計意図を抽出する。 |
| [self-review-html](self-review-html/SKILL.md) | Git 差分と AI セルフレビューを HTML で提示し、指摘に基づいて修正する。 |
| [skill-authoring](skill-authoring/SKILL.md) | Skill の追加、更新、配置判定とカタログ整備を行う。 |
| [to-issues](to-issues/SKILL.md) | 計画や PRD を独立して着手可能な Issue に分割する。 |
| [unknowns](unknowns/SKILL.md) | 未知を分類し、適切な未知管理 Skill を選ぶ。 |
