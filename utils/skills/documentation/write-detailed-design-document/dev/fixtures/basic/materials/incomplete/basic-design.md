# 依頼受付と結果照会の基本設計

本資料は設計案であり、採用や結合試験の完了を示さない。

仲介、受付処理、順序管理、保存リポジトリ、実アダプターを分ける。ローカルJSON通信で、同じ会話に単調増加の受付順を付け、受付情報の保存を確定してから応答する。
受付用識別子と呼出し元の組を一意にし、同じ内容の照合に使う情報と受付順と実行状態を保存する。依頼本文と回答はメモリにだけ持ち、永続保存しない。
失敗した依頼と、切断した依頼の作業は自動再実行しない。切断後の回答は実行基盤から対象依頼を識別して再取得する案である。実アダプターの採用版と再取得経路は未検証であり、模擬アダプターでの内部試験と区別する。
要件の本文保存と自動再実行との不一致は未解決であり、承認した変更記録は提供されていない。入力制約、保存単位、再送の照合、再起動時の状態、取得できないときの結果を詳細設計で具体化する。
