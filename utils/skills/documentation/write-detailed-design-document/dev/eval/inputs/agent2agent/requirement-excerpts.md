## 原資料 requirement.md 433行目

専門エージェントが承認を必要とする操作を要求した場合、人間がWails画面で内容を確認し、許可または拒否を判断できる。画面が閉じている場合は、承認画面を自動で表示する。承認の待ち時間を設定でき、時間内に回答がなければ拒否として扱う。判断結果を対応する専門エージェントへ返す。
