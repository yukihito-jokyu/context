# pptx からテンプレートを作る

pptx の「見た目の決まり」を学んで、`template/<name>/` を作る手順。作ったテンプレートは `init <deck> --template <name>` で使う。

## 目次

1. テンプレートにするもの・しないもの
2. 取り出す（extract）
3. 読む
4. 下書きを作る
5. 比べて直す（最大3回）
6. 仕上げ

## 1. テンプレートにするもの・しないもの

テンプレートは「どんな中身でも載せられる型」。元の資料を写したもの（具体）にしない。

| テンプレートにする（抽象） | テンプレートにしない（具体） |
|---|---|
| 色の組み合わせと役割（地・文字・強調・補助） | 書かれている文章・見出し・数字・データ |
| フォントの種類・太さ・大きさの比 | 写真・イラストの中身、ロゴ、題材に固有のアイコン |
| 背景の作り方（単色・グラデーション・繰り返しの模様） | 1枚にしか出てこない飾り |
| 何度も出てくる飾り（線・枠・図形の形） | 図形の位置を寸分たがわず写すこと |
| 骨組み（余白・段組み・見出しの位置の割合） | 元の資料の枚数や順番 |
| 2枚以上に出てくる構図（シーンの型にする） | |

- `extract` は文章を取り出さない（文字数と書式だけ）。写真などの絵も保存しない（保存するのはレイアウト・背景の絵と、何度も出る小さい飾りの絵だけ）。
- 見本のシーンの文章は、元の資料と関係なく新しく書く。
- 元のスライドの絵（`ref/`）は見比べるためのもの。テンプレートに入れない。

## 2. 取り出す（extract）

```bash
node scripts/motion.mjs extract <pptx> <出力フォルダ>   # 出力フォルダはスキルの外（コミットしない）
```

| 出力 | 中身 |
|---|---|
| `extract.json` | スライドの大きさ、テーマの色とフォント、よく使う色（`colorsUsed`）とフォント（`fontsUsed`）、マスター・レイアウト（よく使う順、`slides` に使ったスライドの番号）・スライドごとの図形（種類・`box`＝幅と高さに対する割合・塗り・線・文字数と書式）、絵の一覧 |
| `media/` | 飾りの絵だけ（マスター・レイアウト・背景に使う絵、2か所以上に出る小さい絵）。題材に固有のアイコンが混ざることがあるので、使うかは読んで決める |
| `ref/slide-NN.png` | 元のスライドの絵（LibreOffice を画面なしで使う。ないと作らない: `brew install --cask libreoffice`） |

## 3. 読む

1. `ref/` を全部見て、スライドを構図でまとめる（表紙・章の扉・見出し＋本文・左右の2段・カードの並び・数字の強調・写真と文・まとめ など）。2枚以上あるまとまりを「シーンの型」の候補にする。`layouts[].slides` と、`slides[].shapes` の並び（種類と `box`）が似ているものが手がかり。
2. 色の役割を決める。地が暗いなら、箱の下地（`--white`）も暗い色にし、枠と影は「上書き」で変える。`colorsUsed`（面積の多い順）と `theme.colors` から、地（`--paper`）・文字（`--ink`）・弱い文字（`--muted`）・強調（`--cyan` ほか）を当てる。
3. 文字の決まりを決める。`text.sizePt` の大きい順に表示・見出し・本文・注記の比を出す。フォントは `fontsUsed` と `theme.fonts`。手元にないフォントは、近いもの＋`"Hiragino Sans"` を後ろに付ける。フォントのファイルは pptx から取り出さない。
4. 背景と飾りを決める。全面の `fill.type: "image"`（`media/` にある）か単色・グラデーションか。何度も出る線・枠・角丸・図形の形を「飾り」として書き出す。模様や飾りは、`media/` の絵をそのまま使わず、できるだけ CSS や SVG で描き直す（元の絵を持ち込まない）。どうしても絵を使うときは `motion/assets/` に置き、`url("assets/…")` で読む。

## 4. 下書きを作る

`template/default/` を写して、見た目に関わるところだけ変える。章バーは default だけの部品なので、写したら外す（雛形 `deck/index.html` と見本帳 `index.html` の `#composition` を `data-chapter-bar="off"` にし、`kit.css` から章バーの見た目を消す）。`check` は雛形に従い、このテンプレートのデッキには章バーを求めない。字幕の帯は残す。

```bash
cp -R template/default template/<name>
cp <pptx> template/<name>/source.pptx   # 元の pptx を同封する（人が見るため。git の対象外）
```

| ファイル | 変えること |
|---|---|
| `source.pptx` | 元の pptx をそのまま置く。人が見比べるためのもので、実装では読まない。`.gitignore` でコミットしない |
| `motion/kit.css` | `#composition` の変数の**値**（名前は変えない。部品と実行系がこの名前を使う）、`--jp`、背景、字幕の見た目。章バーの見た目（`.md-chapters`・`.md-chapter*` の規則）と、章バーだけが使う変数 `--track` は消す。部品の形（枠・影・角丸・文字の太さ）の違いは末尾の「このテンプレートの上書き」に、新しい飾りと構図の組み立て用のクラスは「テンプレートの飾り」にまとめる |
| `motion/kit.js` | 変えない |
| `deck/` | シーンの型ごとに1シーンの見本デッキ。文章は新しく書く。`script.json` の `title` も変える。`index.html` の `#composition` は `data-chapter-bar="off"` |
| `deck-pptx/` | PPTX専用の見本（必ず作る）。`deck/` と同じシーンの型を、動きを使わない完成した1枚で書く（[シーンの書き方](authoring.md)の1）。`script.json` の `"format": "pptx"` は残す |
| `style.md` | 1〜4章（骨格・色と文字・部品・シーンの型）をこのテンプレートの決まりに書き直す。冒頭の題と前書き、6章「やらないこと」の default の色の意味（青＝主役 など）もそろえる |
| `index.html` | 見本帳。構図の `<section>` と `CATALOG` の `c-*` を、このテンプレートのシーンの型に入れ替える（見本帳の字幕に文の名前はないので `data-at` は番号で書く）。部品の見本 `d-*` は残し、default の題材に寄った中身は題材を選ばない中身に書き換える。飾りがあれば見本（`d-decor`）を足す（飾りがなければ足さない）。`#composition` は `data-chapter-bar="off"` |

構図の高さ（px で決めず下の余白まで伸ばす）、PPTX で画像になる CSS、`data-anim` と `data-active` の分け方、3か所の見本のそろえ方は、[会話からテンプレートを作る](template-from-talk.md)の3章の注に従う。

## 5. 比べて直す（最大3回）

1. 見本デッキを作って静止画を撮る（スキルの外に作る）。

   ```bash
   node scripts/motion.mjs init <作業フォルダ>/sample --template <name>
   node scripts/motion.mjs still <作業フォルダ>/sample --cues --subtitles 0
   ```

2. シーンの型ごとに、元の絵（`ref/slide-NN.png`）とシーンの静止画を見比べ、違いを次の表に書く。**文字の中身は比べない。**

   | 観点 | 見ること |
   |---|---|
   | 色 | 地・文字・強調の色と、その面積の釣り合い |
   | 文字 | 太さ、見出しと本文の大きさの比、そろえ（左・中央） |
   | 骨組み | 余白、段の数、見出しと本文の位置の割合 |
   | 背景 | 地の作り方（単色・グラデーション・模様） |
   | 飾り | 線・枠・角丸・図形の形と太さ |

   `--cues` の絵は文の終わりなので、消える途中の要素が半透明に写ることがある（崩れではない）。
3. `kit.css`・見本デッキを直して撮り直す。表の違いがなくなるか3回で止め、残った違いを書き出す。
4. 毎回の終わりに「具体化していないか」を確かめる。元の文章・写真・ロゴが入っていないか、1枚にしかない飾りを写していないか、位置を写しすぎて別の中身が載らない形になっていないか。

## 6. 仕上げ

- `node scripts/motion.mjs check <作業フォルダ>/sample` がエラー 0 件（見本は声を作らないので「仮の尺」などの注意は気にしない）。
- PPTX専用の見本も、`node scripts/motion.mjs init <作業フォルダ>/sample-pptx --template <name> --format pptx` で作り、`check <作業フォルダ>/sample-pptx` がエラー 0 件。
- `node scripts/motion.mjs pptx <作業フォルダ>/sample` で書き出し、最後の「図形にできず画像にした要素」の一覧を見る。図形にできる範囲（[プレイヤーと書き出し](player.md)の `pptx`）で同じ見た目にできるものは `kit.css` を直し、画像のまま残すものは作った人に伝える。
- 見本帳（`template/<name>/index.html`）を開いて、部品と構図が崩れていないか見る。
- 残った違いと、テンプレートにしなかったもの（写真・1枚だけの飾りなど）を、作った人に伝える。
- 仕上げたあとは、[会話からテンプレートを作る](template-from-talk.md)の5章「指摘で直す」で直せる。
