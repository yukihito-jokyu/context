# compareから引き継いだ内容

参照元はcontextのコミット`96b751b4546ddf3a04b5788411bbf9688331501d`にある`utils/skills/discovery/compare/`。

| 参照元の関心 | explain-htmlでの対応 |
| --- | --- |
| 対象名・読者・目的の確認 | 保持。分野を限定せず、題材を初めて学ぶ読者を既定にする |
| 公式資料と版、仕様・解釈・仮定の区別 | 保持。制度原文、科学の一次資料、対象地域・施行日も扱う |
| 仕様一覧と説明先、全情報の逆照合 | 保持。題材に合わせた項目一覧とし、非技術項目を技術分類へ強制しない |
| 説明順と前提、主体・対象・因果 | 保持。単一題材の全体像、具体例、詳細、条件と例外へ並べ替える |
| ページごとの全体図と入口 | 保持。資料ページも含め、Archify標準画像と実座標のリンクを使う |
| 図とコード・設定の対応 | 保持。一般題材では図と書類・記録・式・観測値を対応させる |
| 左右比較・共通入力・A/B色・使い分け | 単一題材の説明へ変更。比較相手と左右同期を必須にしない |
| 有限の経路再生と段階操作 | 保持。固定のHooks/Mods・4段階の例を、任意段階・標準SVG実経路へ変更する |
| ページ移動・直接リンク・履歴・連続操作 | compareの汎用ナビ処理を保持。移動前に再生を止めるイベントと印刷の補足展開を追加 |
| ライト配色、大きい文字、余白、レスポンシブ | 保持。比較用列を外し、本文と図・具体物の幅へ適用する |
| 同梱依存・同期・標準エクスポート | バイト単位で保持。コピーの取得経路と元の同期記録を区別する |
| 機械検査と意味・表示レビューの区別 | 保持。技術と一般題材の実例で個別に記録する |

generative-claude-uiの全機能を同梱・移植したものではありません。文章、図、文字組みとナビのパターンを引き継ぎ、依存のArchifyを独立した配布単位へ同梱します。
