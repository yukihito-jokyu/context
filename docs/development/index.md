# コミット・PR・レビュー

変更を評価し、履歴とレビュー依頼を整えます。

| スキル | できること |
| --- | --- |
| [self-review-html](self-review-html.md) | 差分の評価をHTMLで確認する |
| [commit](commit.md) | 変更を小さな単位でコミットする |
| [pr](pr.md) | 変更理由と確認結果をPRにまとめる |

組み合わせて使う場合は[ワークフロー](../workflows.md)を参照してください。各ページには入力と成果物の例を掲載しています。
