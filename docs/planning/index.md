# 計画・Issue分割

調査結果と人間の判断を、着手できる計画やIssueへ変えます。

| スキル | できること |
| --- | --- |
| [plan](plan.md) | 重要判断を先頭にした実装計画を作る |
| [grill-issue](grill-issue.md) | Issueの未決定事項を詰める |
| [to-issues](to-issues.md) | 計画を着手可能なIssueへ分割する |

組み合わせて使う場合は[ワークフロー](../workflows.md)を参照してください。各ページには入力と成果物の例を掲載しています。
