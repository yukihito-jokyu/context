# 記録・説明

作業や判断の根拠を残し、読み手が理解できる説明へ変えます。

| スキル | できること |
| --- | --- |
| [agent-trace](agent-trace.md) | 操作の証跡と再現手順を残す |
| [issue-trace](issue-trace.md) | Issueを進めながら根拠を記録する |
| [notes](notes.md) | 実装中の判断と逸脱を残す |
| [pitch](pitch.md) | 背景と判断理由を説明する |
| [explanation-design](explanation-design.md) | 読者が理解できる説明順を設計する |

組み合わせて使う場合は[ワークフロー](../workflows.md)を参照してください。各ページには入力と成果物の例を掲載しています。
