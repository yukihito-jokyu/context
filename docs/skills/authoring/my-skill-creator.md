# my-skill-creator

新しいスキルを作る、既存スキルを改善する、出力品質や呼び出し精度を確認したいときに使います。目的を合意し、候補版を検証しながら改善します。

## 渡す情報

達成したい作業、使うタイミング、期待する出力、参考例、成功条件、保存先を渡します。

## 依頼例

```text
my-skill-creatorを使って、調査結果を根拠付きでまとめるスキルを設計したいです。入力はコードとIssue、出力は調査Markdownです。構成を確認してから作成し、架空の調査例で品質を評価したいです。
```

## 進め方

1. 目的、構成、保存先、未確定事項を確認します。既定の簡易モードか詳細モードかを決めます。
2. 合意後にスキルを作成・変更し、必要な評価ケースと検証を用意します。
3. 評価結果から反復して改善し、正本への反映を確認します。

## 成果物の例

my-skill-creatorの初回手順を実際に適用して得た構成提案です。表示したtreeは提案であり、生成済みの候補スキルではありません。

**到達点：初回構成提案・構成確認待ち。**

**移行時の確認：既存の実行記録を移行しました。本文の一致は確認しましたが、過去の実行時の同梱資料全体は特定できていません。**

このハッシュは移行時の変更検出用の基準です。同梱資料全体をこの版で再実行した証拠ではありません。

### 実行した依頼

```text
実成果物展示を更新するスキルを検討する場合の目的、スキル本体の構成、生成成果物の構成、保存先、重要な未確定事項を簡易モードで提示してください。構成確認前に候補を作成しないでください。
```

### 実出力の抜粋

以下は保存した原本の冒頭です。全文は原本から取得できます。

````markdown
# スキル構成の提案

今回の実成果物展示への依頼を入力として、繰り返す実例更新をスキル化するならどの構成が必要か検討した。my-skill-creatorの簡易モードの初回出力。構成確認前のため候補スキルの作成・評価は実行していない。

## 目的

実行した依頼と得られた成果物を保存し、Markdownの説明ページへ画像と原本取得を反映する。

## スキル本体の構成案
````

## 確認するポイント

これは既存スキル改善時の作業領域を含む例です。簡易モードを既定とし、詳細な検討は指定した場合に行います。新規作成と改善で比較対象が異なり、評価や正本反映には人間の確認が入ります。
