# 音声・メディア

文章の読み上げやBGM、ナレーション付きのスライドや解説動画など、音声を伴うメディアを作ります。

| スキル | できること |
| --- | --- |
| [local-tts](local-tts.md) | ローカルの音声合成（VoxCPM2・OmniVoice・S2 Pro）で文章を読み上げ、WAVを作り、声を登録する |
| [remote-tts](remote-tts.md) | LAN上の別PCのAPIで文章を音声にし、使えなければこのPCのlocal-ttsへ切り替える |
| [motion-deck](motion-deck.md) | ナレーションに合わせて動くスライドを作り、動画・発表・PowerPointの書き出しに使う |
| [loop-bgm](loop-bgm.md) | 設計図からオリジナルのループBGMを数式合成で作り、気になるパートだけを直す |

組み合わせて使う場合は[ワークフロー](../workflows.md)を参照してください。各ページには入力と成果物の例を掲載しています。
