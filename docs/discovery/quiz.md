# quiz

実装後やレビュー前に、自分の理解の抜けを確認したいときに使います。用語の暗記ではなく、変更理由と影響を問います。

## 渡す情報

変更内容、重要判断、実装ノート、説明資料、エッジケースを渡します。

## 依頼例

```text
quizを使って、担当者フィルターの変更を理解するための問題と解答を作ってください。URLへの条件保存と未割り当て依頼の扱いを重点にしてください。
```

## 進め方

1. 重要な設計判断と影響範囲から問題を作ります。
2. 例外条件も問題へ含めます。
3. 解答と、理解できていない場合に読む箇所を示します。

## 成果物の例

実際の設定、配布ファイル、検索実行結果に基づく5問と解答です。

**到達点：理解確認問題の作成。**

### 実行した依頼

```text
実成果物展示の実装と実行記録から、判断理由、原本配信、ZIP、承認との違い、検索入力の影響を問う理解確認クイズを解答付きで作成してください。
```

### 実出力の抜粋

以下は保存した原本の冒頭です。全文は原本から取得できます。

````markdown
# Review Quiz

## 1. クイズ

### Q1

なぜMarkdown原本をdocs/artifactsへ置くだけでは不十分で、文書探索からの除外が必要なのか。

### Q2

HTML原本をダウンロードするリンクを、通常の文書リンクと区別する理由は何か。

### Q3

React成果物はなぜindex.htmlだけではなく、画面一式のZIPで渡すのか。

````
