# 再送・停止の設計

問いは、同じ依頼をいつ再送し、いつ停止するか。workflow v2を選び、202と503を順次応答でなく代替分岐として描いた。①から③が受付正常経路、503だけが④へ入る。④から⑤へ戻る条件は初回を含め1・2回目、3回目は⑥で止まる。⑥からジョブfailedへの矢印はない。

図は短い番号と動作、応答値、送信上限、job_17に絞った。画像ID・requestKey: req_42・サーバーの重複防止・未定義応答・HTTP一般仕様との区別は同番号のasideへ置いた。主語はレーンとasideでクライアントと明示する。

Archify標準SVGは無改変。col 0/2/4の幅916に対し、0/1/2へ詰める候補は未使用ランクも保持するv2契約により幅1031となったため不採用。schemaの明示viewBox幅下限は700であり、250〜320指定はできない。図内フォントはレンダラー固定で、狭幅の18〜19px目標は達成できない。この制約を検査合格と同一視しない。
