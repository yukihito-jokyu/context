# 成果物リンクの確認

1. 対象ページと実行成果物の原本を読む。
2. 本文の出力抜粋が原本に含まれることを確認する。
3. 画面画像が同じ原本を実際に開いて撮影したものか確認する。
4. 取得リンクが原本に届くことを確認する。複数ファイルは参照関係を保ったZIPを使う。
5. 確認済みの項目と未確認の項目を分けて報告する。未実施の実行・検証を成功と記載しない。

対象ページ、原本、画像の出典、取得リンクの結果をMarkdownで返す。
