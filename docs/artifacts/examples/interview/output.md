# Interview

## 現在確認すべき最重要質問

実際にこの会話で提示した質問:

> pr・to-issuesなどGitHubへの作成を伴うスキルの実行例は、どこまで進めますか？ その他のスキルは、公開可能なサンプル題材を使って実際に成果物を生成・検証します。

提示した選択肢:

1. 投稿前のPR本文・Issue草案まで実行し、到達点を明記する。
2. 専用のGitHubリポジトリにサンプルPR・Issueも作成する。

## この質問が重要な理由

外部にPRやIssueを作ると、ドキュメントのファイル生成だけでなくGitHub上の操作が発生する。掲載できる実例の到達点が変わる。

## 回答によって変わること

- 草案までの場合は、実差分から作ったPR本文と実計画から分割したIssue案を保存する。
- 外部作成の場合は、作成先を確定して実投稿とURLの確認まで行う。

## 回答後に更新する項目

- 実例の実行範囲、作成先、到達点、検証方法。

## 現在の状態

質問への回答はまだ得ていない。ユーザーからは、修正対象がdocsのすべてのスキルの成果物例であると改めて指摘された。外部作成の承認と解釈せず、他の例の実行を進める。
