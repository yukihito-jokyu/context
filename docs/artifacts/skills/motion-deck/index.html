ブランチ ＝ 作業の分かれ道

本流を守ったまま、別の作業を進める
main
feature/login
枝で何を試しても、main は無事

枝を作って、移る

使うコマンドは 2つ
Switched to a new branch 'feature/login'
$ git branch
main
* feature/login
$ git commit -m "ログイン画面"
1 file changed

今いる枝

main feature/login
コミットは、この枝にだけ積まれる

枝を合流させる

今日のまとめ

main
feature/login
git switch main
git merge feature/login
git switch -c
新しい枝を分ける
git switch
枝のあいだを移る
git merge
枝を main に合流させる
次は、小さな枝を一本作ってみる
