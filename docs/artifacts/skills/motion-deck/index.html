Git のブランチ入門
ブランチ ＝ 作業の枝分かれ
作る移る合流する
main は そのまま
main
feature/login
実験

ブランチを作って、移る

$ git switch -c feature/login
Switched to a new branch 'feature/login'
$ git branch
* feature/login
  main
$ git switch main
Switched to branch 'main'
-c で 作って移る
* ＝ 今いる枝
main に戻る
コミットは 枝に残る

終わったら合流させる
