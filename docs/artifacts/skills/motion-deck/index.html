Gitのブランチ入門
作業の流れを枝分かれさせる
main
feature/login
main は そのまま

枝を作って、移る

$ git switch -c feature/login
$ git branch
* feature/login
  main
$ git switch main
-c ＝ 作って、すぐ移る
枝の一覧を見る
* ＝ 今いる枝
main に戻る
main
feature/login

終わったら main に合流

main
