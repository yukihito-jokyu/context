## 開き方

- 発表：`open "<work>/git-branch/index.html?mode=live"`。→・Space・クリック・リモコンで1ステップずつ進み、←で戻る。`N`で発表者ビュー（今話すこと・次のクリック・台本・メモ・経過時間）。`V`でナレーションのオン・オフ（オンならクリックごとにその文を読み上げる）。`B`/`W`で画面を隠す。
- 動画：`open "<work>/git-branch/index.html"`。`P`で発表モードと切り替え。
- PowerPoint：`git-branch.pptx`。1文＝1クリック、ノートに台本（【スライド開始】【クリック n】の区切り）と文・シーンのメモ。
- PDF：`git-branch.pdf`。発表の1ステップ＝1ページで、音声なしで配る資料に使える。

直したい所は、動画モードで開いたプレーヤーの左右の列で伝えられます。`I`（DOM選択）でステージの要素を、右の原稿で文を、左のシーンの「＋」でシーン全体を選び、指示を書いて「指示を追加」で溜め、「全部コピー」した文をそのまま貼ってください。

## 確かめたこと

- `check`：音声なしの段階でエラー0件・注意2件（仮の尺、ナレーションの切り替え未確認）。synth と timeline の後にエラー0件・注意0件、発表モード12ステップ。
- `still --cues`（12枚）と `still --live`（12ステップ、別の出力先）の一覧画像を見て、見出しが左上、太枠とずらした影、紙色の背景、章バーと字幕の帯（動画のみ）がそろっていることを確認。最初の一覧で枝の縦線がコミットの丸の上に重なって見えたため、丸を線より前に出した。
- `pdf`：12ページ。PDFKitでページ数（発表のステップ数と同じ）、文書のタイトル（script.json の title と同じ）、全ページで文字を取り出せること、字幕の文が入っていないことを確認。1・4・6・9・10・12ページをPNGにして、同じステップの `still --live` と並べて見比べ、配置が一致することを確認。
- `pptx`：XMLで、文字がテキストボックスに入っていること、アニメーションの対象がグループか画像であること、画面の切り替え（フェード・プッシュ）、ノートの台本とメモを確認。走るキャラクター（SVG）は図形にできず画像になった。
- プレーヤーの修正の列：動画モードで `I` → feature/login の札をクリック → 指示を入力 → 「指示を追加」で、溜めた指示が1件になることを確認。
