## 開き方

| 使い方 | 開き方 |
|---|---|
| 人が発表する | `open "<work>/git-branch/index.html?mode=live"`。→・Space・クリック・リモコンで1ステップずつ進み、←で戻る。`N`で発表者ビュー（今話すこと・次のクリック・台本・経過時間）。`V`でナレーションのオン・オフ（`&narration=1`で最初からオン）。`B`/`W`で画面を隠す |
| 動画として見せる | `open "<work>/git-branch/index.html"`（動画モード）。`P`で発表モードと切り替え |
| PowerPoint | `git-branch.pptx`。1画面＝1スライド、1文＝1クリック。ノートに台本（【スライド開始】【クリック n】の区切り）とメモ |

## 直したい所の伝え方（修正の列）

動画モードで開くと、ステージの左右に修正の列が出る（発表モードでは`E`で出せる）。

1. 左の「シーン」で、シーンへ移る。シーン全体を直したいときは「＋」で対象にする。
2. 要素なら右上の「DOM選択」か`I`でステージの要素をクリックする。文なら右の「原稿」で文を押す。
3. 「対象と指示」に直したいことを書いて「指示を追加」（⌘/Ctrl＋Enter）。
4. 「全部コピー」で、「motion-deck のデッキを直してください。」で始まる文をそのまま Claude に貼る。
5. 直ったら再読み込みして確かめ、済んだ指示を「×」か「全部消す」で消す。

`player-edit.png` は、switch の文3（star）のときに`I`で注釈のカード「＊ ＝ 今いる枝」を選び、「この注釈カードを、コードの＊の行の横に寄せたい」と書いて指示を1件溜めたところ（選択モードは終わった状態。ヘッドレスの Chrome、1600×900）。

## シーンの構成

| シーン | 尺（音声） | 型 | 画面 |
|---|---|---|---|
| idea（ブランチとは） | 20.6秒 | 色帯の見出し＋分岐する線と走者 | `main`の線とコミットを描き、`feature/login`の枝が分かれて走者が進む。最後に結論のカード「main は そのまま」 |
| switch（作って移る） | 20.0秒 | コードの解説 | 左にターミナルのコマンド（文ごとに強調する行が移る）と差し替わる注釈カード、右に今いる枝の図（走者が枝と main の間を移る） |
| merge（合流とまとめ） | 18.8秒 | 図＋ターミナル → まとめ | 枝が main に戻る線、`git merge feature/login`を打つ。見出しごと`.summary`の3行（switch -c／switch／merge）に差し替え |

切り替えは idea→switch が slide、switch→merge が iris。`scenes.js`には switch の走者の上下の移動（`Motion.scene`）だけを書き、ほかは `data-*` と部品で書いた。

## 静止画で見て確かめた範囲

- `contact.png`（各文の終わり13枚）と `live-contact.png`（発表の13ステップ）を全枚数見た。
- 見出しは左上（色帯つき1つ、通常の見出し3つ）、カードとコードは太枠とずらした影、紙色の背景、上の章バー、下の字幕の帯がそろっている。
- 色の意味：青＝枝（主役）、黒＝main、黄＝注釈、緑＝結論・合流。
- `still --cues` は次の文の直前を撮るため、`data-until` で消える要素（switch の注釈カード、merge の前半）は消えかけの薄い状態で写る。発表のステップ（`live-contact.png`）ではどれも完全に表示されている。
- merge の文2（recap「今日のまとめです。」）の時点は見出しだけで、表は文3で出る。

## 作業の流れ

1. `init`（テンプレートは既定）→ 雛形と仮の timeline.js（6シーン）
2. `script.json`（3シーン・13文）、`lexicon.json`（Git→ギット）、`index.html`・`theme.css`・`scenes.js` を書いた。コマンドを含む文は`say`で読みを与えた
3. `check`（音声なし）→ エラー0件、注意2件（仮の尺、ナレーションの切り替えは未確認）
4. `still --cues` → 一覧を見て、switch の走者と枝のラベルが重なっていたので位置をずらした
5. `synth --dry-run` → 3シーン・344文字、目安 約3分
6. `synth`（バックグラウンド）→ 終了コード0、155秒。idea 20.6秒・switch 20.0秒・merge 18.8秒
7. `timeline` → 3シーン、1.09分（1956フレーム）、音声あり
8. `check` → エラー0件、注意0件、発表モード13ステップ（`check.log`）
9. `still --cues`（`contact.png`）と `still --live --out out/live`（`live-contact.png`）を見て確認
10. `pptx` → 4スライド。ノートに台本とメモが入っていることを確かめた
11. `local-tts server stop` → 「No server started by this tool is running」。VoxCPM2 と OmniVoice のサーバーはこの実行の前から別に起動されていた（`started elsewhere`）ので、止めずに残した
12. 修正の列の画面（`player-edit.png`）を、ヘッドレスの Chrome で動画モードのフレーム1146を開き、Chrome DevTools Protocol で`I`→要素のクリック→指示の入力→「指示を追加」と操作して撮った
