## 開き方

| 使い方 | 開き方 |
|---|---|
| 人が発表する | `open "<work>/git-branch/index.html?mode=live"`。→・Space・クリック・リモコンで1ステップずつ進み、←で戻る。`N`で発表者ビュー（今話すこと・次のクリック・台本・経過時間）。`V`でナレーションのオン・オフ（`&narration=1`で最初からオン）。`B`/`W`で画面を隠す |

`pptx` の出力（`pptx.log`）：

|---|---|---|---|---|---|
| idea | 1 | 3 | 16 | 8 | 0 |
| switch | 1 | 4 | 17 | 16 | 5 |

最後の行：「4スライド、図形 62・文字 44・画像 7、グループ 42。要素のアニメーション 13ステップ、差分の重ね 6ステップ」。

図形にできず画像にした要素（1件）：

| シーン | 要素 | 理由 |
|---|---|---|
| switch | `div#sw-runner.runner > svg`（今いる枝を表す走者） | SVG |

枝の線（`main` と `feature/login`）とコミットの丸は、SVG ではなく箱（`theme.css` の `.line` と `.commit`）で描いた。線は角が直角の横線と縦線の組み合わせにし、`wipe`・`grow-y`・`wipe-down` で伸ばしたので、PPTX でも図形のままワイプのアニメーションになった。

画像7枚の内訳は、上の走者1枚と、差分の重ね6枚（switch の4ステップ：コードの強調行の移動と走者の移動、merge の2ステップ：ターミナルの打ち込みと出力の行で箱が伸びる所）。

PPTX の XML（`ppt/slides/slide1〜4.xml`、`ppt/notesSlides/`）で次を確かめた。

- 文字はテキストボックス（`txBox="1"`、スライド順に8・16・9・11個）の `a:t` に入っている（章バーの章名、見出し「作業の流れを／枝分かれ／させる」、`main`・`feature/login` のラベル、ターミナルの5行、注釈カード、`Merge made by the 'ort' strategy.`、まとめの表など）。
- グループ（`p:grpSp`）はスライド順に14・11・13・4個。アニメーションの対象（`p:spTgt`）は、グループが43・32・13・7件、画像が0・8・4・0件（画像は走者と差分の重ね）で、単独の図形を対象にしたものはない。
- 効果はスライド順に、出現13・14・7・2件、終了（`data-until` で差し替わる注釈カード）は switch の3件。クリックの起点は3・4・1・1件。
- 画面切り替えは idea→switch がプッシュ（`p:push dir="l"`）、switch→merge が円（`p:circle`）、merge の2枚目がフェード（`p:fade`）。
- ノート（`notesSlide1〜4`）に台本と、シーンのメモ「聞き手はGitを使い始めたばかり。木の枝のたとえで話す」、文のメモ「＊の行を指さす」が入っている。
- `docProps` の作成者とアプリケーションは `motion-deck`。unzip した全ファイルを grep し、絶対パス・ユーザー名・メールアドレスは見つからなかった。画像（`ppt/media/*.png`）にテキストのメタデータはない。

PowerPoint で開いての再生は確かめていない（XML の確認まで）。

## 直したい所の伝え方（修正の列）

動画モードで開くと、ステージの左右に修正の列が出る（発表モードでは`E`で出せる）。

1. 左の「シーン」で、シーンへ移る。シーン全体を直したいときは「＋」で対象にする。
2. 要素なら右上の「DOM選択」か`I`でステージの要素をクリックする。文なら右の「原稿」で文を押す。
3. 「対象と指示」に直したいことを書いて「指示を追加」（⌘/Ctrl＋Enter）。
4. 「全部コピー」で、「motion-deck のデッキを直してください。」で始まる文をそのまま Claude に貼る。
5. 直ったら再読み込みして確かめ、済んだ指示を「×」か「全部消す」で消す。

`player-edit.png` は、switch の文3（star）のとき（フレーム1247）に`I`で注釈のカード「＊ ＝ 今いる枝」を選び（緑の枠）、「この注釈カードを、コードの＊の行の横に寄せたい」と書いて「指示を追加」し、溜めた指示に1件入ったところ。右の「対象と指示」に、セレクタ・`data-*`・文字・見ていた画面「文3（star）のとき」が出ている（ヘッドレスの Chrome、1600×900、Chrome DevTools Protocol で操作）。

## シーンの構成

| シーン | 尺（音声） | 型 | 画面 |
|---|---|---|---|
| idea（ブランチとは） | 23.6秒（22.0秒） | 色帯の見出し＋分岐の図 | `main`の線を引いてコミットを並べ、`feature/login`の枝が縦に分かれて横に伸びる。最後に結論のカード「main は そのまま」 |
| switch（作って移る） | 23.5秒（21.9秒） | コードの解説 | 左にターミナルのコマンド（文ごとに強調する行が移る）と差し替わる注釈カード、右に今いる枝の図（走者が枝と main の間を移る） |
| merge（合流とまとめ） | 23.0秒（20.4秒） | 図＋ターミナル → まとめ | 枝の途中で main にもコミットが進み、`git merge feature/login` で枝が main に下りて合流のコミット（緑）ができる。見出しごと`.summary`の3行（git switch -c／git switch／git merge）と結論のカードに差し替え |

切り替えは idea→switch が slide、switch→merge が iris。`scenes.js`には switch の走者の上下の移動（`Motion.scene`）だけを書き、ほかは `data-*` と部品で書いた。

## 静止画で見て確かめた範囲

- `contact.png`（合成後の各文の終わり13枚）と `live-contact.png`（発表の13ステップ）を全枚数見た。音声なしの段階の `still --cues` も見た。
- 見出しは左上（色帯つき1つ、通常の見出し3つ）、カードとコードは太枠とずらした影、紙色の背景、上の章バー、下の字幕の帯がそろっている。
- 色の意味：青＝枝（主役）、黒＝main、黄＝注釈、緑＝結論・合流。
- `still --cues` は次の文の直前を撮るため、`data-until` で消える要素（switch の注釈カード、merge の前半）は消えかけの薄い状態で写る。発表のステップ（`live-contact.png`）ではどれも完全に表示されている。
- switch と merge の後半は画面の下側に余白が残る（default テンプレートでは check の「下が空いた」注意の対象外）。

## 作業の流れ

1. `init`（テンプレートは既定）→ 雛形と仮の timeline.js（6シーン）
2. `script.json`（3シーン・13文）、`lexicon.json`（Git→ギット）、`index.html`・`theme.css`・`scenes.js` を書いた。コマンドを含む文は`say`で読みを与えた。枝の線とコミットの丸は PPTX で図形として残るよう、SVG ではなく箱で描いた
3. `timeline` → `check`（音声なし）→ エラー0件、注意2件（仮の尺、ナレーションの切り替えは未確認）
4. `still --cues` → 一覧を見て、図の上の余白が大きかった idea の図と結論のカードを40px上げた
5. `synth --dry-run` → 3シーン・375文字、目安 約3分
6. `local-tts server status` → VoxCPM2 は停止中、OmniVoice は別に起動されていた（`started elsewhere`）
7. `synth`（バックグラウンド）→ 終了コード0、約147秒。idea 22.0秒・switch 21.9秒・merge 20.4秒の音声
8. `timeline` → 3シーン、1.17分（2105フレーム）、音声あり
9. `check` → エラー0件、注意0件、発表モード13ステップ（`check.log`）
10. `still --cues`（`contact.png`）と `still --live --out out/live`（`live-contact.png`）を見て確認
11. `pptx` → 4スライド、図形62・文字44・画像7、グループ42、画像にした要素1件（`pptx.log`）。XML でテキストボックス・グループへのアニメーション・画面切り替え・ノートを確かめ、絶対パス等が入っていないことを grep で確かめた
12. synth が起動した VoxCPM2 のサーバーを `local-tts server stop --engine voxcpm2` で止めた。OmniVoice は別に起動されていたので止めずに残した
13. 修正の列の画面（`player-edit.png`）を、ヘッドレスの Chrome で動画モードのフレーム1247を開き、Chrome DevTools Protocol で`I`→要素のクリック→指示の入力→「指示を追加」と操作して撮った
