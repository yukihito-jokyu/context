## 開き方

| 使い方 | 開き方 |
|---|---|
| 人が発表する | `open "<work>/git-branch/index.html?mode=live"`。→・Space・クリック・リモコンで1ステップずつ進み、←で戻る。`N`で発表者ビュー（今話すこと・次のクリック・台本・経過時間）。`V`でナレーションのオン・オフ（`&narration=1`で最初からオン）。`B`/`W`で画面を隠す |
| 動画として見せる | `open "<work>/git-branch/index.html"`（動画モード）。`P`で発表モードと切り替え |
| PowerPoint | `git-branch.pptx`。1シーン＝1スライド、1文＝1クリック。ノートに台本（【スライド開始】【クリック n】の区切り）とシーンのメモ |

## シーンの構成

| シーン | 尺 | 型 | 画面 |
|---|---|---|---|
| idea（ブランチとは） | 23.5秒 | 色帯の見出し＋分岐する線と走者 | `main`の線を描き、`feature/login`の枝と「実験」の枝が分かれる。結論のカード「main は そのまま」 |
| switch（作って移る） | 25.9秒 | コードの解説 | 左にターミナル風の`pre.code`（文ごとに強調する行が移る）、右に小さな図で走者（今いる枝）が移り、注釈のカードを差し替える |
| merge（合流とまとめ） | 25.6秒 | 図＋ターミナル → まとめ | 枝がメインに戻る線を描き、`git merge`を打つ。最後は`.summary`の3行（switch -c／switch／merge）に差し替え |

切り替えは idea→switch が slide、switch→merge が iris。`scenes.js`には switch の走者の移動（`Motion.scene`）だけを書き、ほかは `data-*` と部品で書いた。

## 実行したコマンドと結果

1. `init` → 雛形と仮の timeline.js（6シーン）を作成
2. `script.json`（3シーン・15文・433文字）、`lexicon.json`（Git→ギット）、`index.html`・`theme.css`・`scenes.js` を書いた。コマンドを含む文は`say`で読みを与えた
3. `check`（音声なし）→ エラー0件、注意2件（仮の尺、ナレーションの切り替えは未確認）
4. `still --cues` → 一覧画像を見て、1シーン目に文0の画面が見出しだけで空く点を直した（三つの動きのチップを追加、走者の色を分けた）
5. `synth --dry-run` → 3シーン・428文字、目安 約3分
6. `synth`（バックグラウンド）→ 終了コード0、153秒。idea 21.9秒・switch 24.3秒・merge 23.0秒の音声
7. `local-tts server stop` → Stopped。`server status` で voxcpm2 が not running
8. `timeline` → 3シーン、1.25分、音声あり
9. `check` → エラー0件、注意0件（`check.log`）
10. `still --cues`（`contact.png`）と `still --live`（`live-contact.png`）を見て確認
11. `pptx` → 3スライド、約5秒で書き出し

## 静止画で見て確かめた範囲

- `contact.png`（各文の終わり15枚）と `live-contact.png`（発表の15ステップ）を全枚数見た。
- 見出しは左上（色帯つき1枚、通常の見出し2枚）、カードは太枠とずらした影、紙色の背景、上の章バー、下の字幕の帯がそろっている。
- 色の意味：青＝枝（主役）、黒＝main、赤＝実験、黄＝注釈、緑＝結論・合流のコミット。
- はみ出し・重なりは check でも 0 件。
- `still --cues` は次の文の直前を撮るため、`data-until` で消える要素（switch の注釈カード、merge の4文目の画面）は消えかけの薄い状態で写る。発表のステップの絵（`live-contact.png`）では、どれも完全に表示されていることを確かめた。
