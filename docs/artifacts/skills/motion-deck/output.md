図形にできず画像にした要素（1件）：

| シーン | 要素 | 理由 |
|---|---|---|
| switch | `div#sw-runner.runner > svg`（今いる枝を表す走者） | SVG |

枝の線（`main` と `feature/login`）とコミットの丸は、SVG ではなく箱（`theme.css` の `.line` と `.commit`）で描いた。線は横線と縦線の組み合わせにし、`wipe`・`grow-y`・`wipe-down` で伸ばしたので、PPTX でも図形のままワイプのアニメーションになった。

画像5枚の内訳は、上の走者1枚と、差分の重ね4枚（switch の4ステップ：コードの強調行の移動と、`Motion.scene` で動かす走者の移動）。merge のターミナルの打ち込みは差分の重ねにならず、図形とテキストのまま出た。

PPTX の XML（`ppt/slides/slide1〜4.xml`、`ppt/notesSlides/`）で次を確かめた。

- 文字はテキストボックス（`txBox="1"`、スライド順に8・17・9・11個）の `a:t` に入っている（章バーの章名、見出し「作業の流れを／枝分かれ／させる」、`main`・`feature/login` のラベル、ターミナルの6行、注釈カード、`Merge made by the 'ort' strategy.`、まとめの表など）。
- グループ（`p:grpSp`）はスライド順に14・14・8・6個。アニメーションの対象（`p:spTgt`）は、グループが43・36・19・16件、画像が0・8・0・0件（画像は走者と差分の重ね）で、単独の図形を対象にしたものはない。
- 効果はスライド順に、出現13・17・6・5件、終了（`data-until` で差し替わる注釈カード）は switch の2件。クリックの起点は3・4・1・1件。
- 画面切り替えは idea→switch がプッシュ（`p:push`）、switch→merge が円（`p:circle`）、merge の2枚目がフェード（`p:fade`）。
- ノート（`notesSlide1〜4`）に台本と、シーンのメモ「聞き手はGitを使い始めたばかり。木の枝のたとえで話す」、文のメモ「＊の行を指さす」が入っている。
- merge の1枚目のターミナルには、打ち込みのカーソル `▍` も文字として入っている（HTML の最後の状態と同じ）。
- `docProps` の作成者とアプリケーションは `motion-deck`。unzip した全ファイルを grep し、絶対パス・ユーザー名・メールアドレスは見つからなかった。画像（`ppt/media/*.png`）にテキストのメタデータはない。

PowerPoint で開いての再生は確かめていない（XML の確認まで）。

## 直したい所の伝え方（修正の列）

動画モードで開くと、ステージの左右に修正の列が出る（発表モードでは`E`で出せる）。

1. 左の「シーン」で、シーンへ移る。シーン全体を直したいときは「＋」で対象にする。
2. 要素なら右上の「DOM選択」か`I`でステージの要素をクリックする。文なら右の「原稿」で文を押す。
3. 「対象と指示」に直したいことを書いて「指示を追加」（⌘/Ctrl＋Enter）。
4. 「全部コピー」で、「motion-deck のデッキを直してください。」で始まる文をそのまま Claude に貼る。
5. 直ったら再読み込みして確かめ、済んだ指示を「×」か「全部消す」で消す。

`player-edit.png` は、switch の文3（star）のとき（フレーム1084）に`I`で注釈のカード「＊ ＝ 今いる枝」を選び（緑の枠）、「この注釈カードを、ターミナルの＊の行の横に寄せたい」と書いて「指示を追加」し、溜めた指示に1件入ったところ。右の「対象と指示」に、セレクタ・`data-*`・文字・見ていた画面「文3（star）のとき」が出ている（ヘッドレスの Chrome、1600×900、Chrome DevTools Protocol で操作）。

## シーンの構成

| シーン | 尺（音声） | 型 | 画面 |
|---|---|---|---|
| idea（ブランチとは） | 19.5秒（17.9秒） | 色帯の見出し＋分岐の図 | `main`の線を引いてコミットを並べ、`feature/login`の枝が縦に分かれて横に伸びる。最後に結論のカード「main は そのまま」 |
| switch（作って移る） | 22.4秒（20.8秒） | コードの解説 | 左にターミナルの行（文ごとに出て、強調する行が移る）、右に今いる枝の図（走者が main と feature/login の間を移る）と、差し替わる注釈カード |
| merge（合流とまとめ） | 21.5秒（19.9秒） | 図＋ターミナル → まとめ | main にもコミットが進み、`git merge feature/login` で枝が main に下りて合流のコミット（緑）ができる。見出しごと`.summary`の3行（git switch -c／git switch／git merge）と結論のカードに差し替え |

切り替えは idea→switch が slide、switch→merge が iris。`scenes.js`には switch の走者の上下の移動（`Motion.scene`）だけを書き、ほかは `data-*` と部品で書いた。

## 作業の流れ

1. `init`（テンプレートは既定）→ 雛形と仮の timeline.js（6シーン）
2. `script.json`（3シーン・13文）、`lexicon.json`（Git→ギット）、`index.html`・`theme.css`・`scenes.js` を書いた。英字の残る文は`say`で読みを与えた。枝の線とコミットの丸は PPTX で図形として残るよう、SVG ではなく箱で描いた
3. `timeline` → `check`（音声なし）→ 文の名前 `end` が使えない名前だったので `rule` に変え、merge 文0 に英字「main」が残っていたので`say`を足した → エラー0件、注意2件（仮の尺、ナレーションの切り替えは未確認）
4. `still --cues` → 一覧を見て、switch の枝名が切れていた所を直した
5. `synth --engine qwen3-tts --dry-run` → 3シーン・364文字、目安 約2分
6. `local-tts server status` → Qwen3-TTS は停止中、OmniVoice は別に起動されていた（`started elsewhere`）
7. `synth --engine qwen3-tts`（バックグラウンド）→ 終了コード0、約97秒。idea 17.9秒・switch 20.8秒・merge 19.9秒の音声
8. `timeline` → 3シーン、1.06分（1901フレーム）、音声あり
9. `check` → エラー0件、注意0件、発表モード13ステップ（`check.log`）
10. `still --cues`（`contact.png`）と `still --live --out out/live`（`live-contact.png`）を見て確認
11. `pptx` → 4スライド、図形70・文字45・画像5、グループ42、画像にした要素1件（`pptx.log`）。XML でテキストボックス・グループへのアニメーション・画面切り替え・ノートを確かめ、絶対パス等が入っていないことを grep で確かめた
12. 修正の列の画面（`player-edit.png`）を、ヘッドレスの Chrome で動画モードのフレーム1084を開き、Chrome DevTools Protocol で`I`→要素のクリック→指示の入力→「指示を追加」と操作して撮った
13. synth が起動した Qwen3-TTS のサーバーを `local-tts server stop --engine qwen3-tts` で止めた。OmniVoice は別に起動されていたので止めずに残した
