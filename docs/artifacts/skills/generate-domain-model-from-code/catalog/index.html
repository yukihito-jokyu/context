確認事項

  • Customer・Subscription・InvoiceにはEntityやValueObjectの基底型・注釈がないためconceptとした。業務上の同一性や値の同値性は未確認。
  • 必須の単一プロパティから参照先の多重度を1とした。顧客ごとの契約数・契約ごとの請求書数・プランごとの契約数はコードから決まらない。
  • readonlyは再代入の制約であり、参照先の生成・削除や寿命の所有を示すものではない。関係はassociationとした。
  • 領域は宣言元ディレクトリに基づく配置単位であり、業務上の境界としての妥当性は未確認。
