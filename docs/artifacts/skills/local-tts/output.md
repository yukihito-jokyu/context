## 読みの確認（check）

`check` で聞き取った読みと原稿を照らし合わせました（結果は `check.json`）。

| 区間 | 原稿 | 聞き取った読み | 判断 |
|---|---|---|---|
| 1 | 本日はお集まりいただき、ありがとうございます。 | ホンジツワオアツマリイタダキアリガトーゴザイマス | 正しい。「ワ」（は）と「トー」（とう）は書き方の違いだけ（認識の誤り）で、直していません |
| 2 | 発表の時間は十五分です。 | ハッピョーノジカンワジューゴフンデス | 正しい。「十五分」は「ジューゴフン」と読めています。「ピョー」「ワ」は書き方の違いだけです |

誤読は見つかりませんでした。そのため `redo` は行っていません。

## サーバーの停止

Qwen3-TTSのサーバーは、作業を始める前から別に起動されていました（started elsewhere）。ログで直前の生成が終わっていて、ほかの接続がないことを確かめてから合成しました。

`server stop` の出力は次のとおりです。このツールが起動したサーバーではないので、止まらずに動いたままです。

```text
No server started by this tool is running
```

## 聞いて確かめていない範囲

音声は再生しておらず、聞いて確かめていません。`check` で分かるのは読み（音）だけで、アクセントとイントネーションは未確認です。長さと音量の数値も、聞いて確かめたことの代わりにはなりません。

試聴していただきたい箇所:

- 2文目の「十五分」（数字の読みとアクセント）
- 1文目の「お集まりいただき、」の読点のところの間の取り方と、文末の「ありがとうございます」のイントネーション
- 2文の間の間（`break` は入れていません）が自然か
