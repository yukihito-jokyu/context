# 音声ファイルの報告

| 項目 | 内容 |
|---|---|
| ファイル名 | `sample.wav`（区間ごとの時間は同名の `sample.json`） |
| 合計の長さ | 6.1秒（うち発話 5.6秒、文の間の無音 0.5秒） |
| 形式 | WAV、PCM 16bit、48,000 Hz、モノラル |
| 使った声 | `<個人名>`（設定の既定の声） |
| エンジン | `voxcpm2`（既定のエンジン） |
| 再生の有無 | 再生していません（`speak` で作成、`playback_enabled: false`） |

原稿は2文を `<s>` に分け、間に `<break time="500ms"/>` を置きました（`sample.ssml`）。`plan` で区切りが2発話と0.5秒の間になっていることを確かめてから合成しました。

## 聞いて確かめた範囲

なし。この環境には音声を聞く手段がないため、耳では確かめていません。

機械的に確かめたのは次の点だけで、読み方の正しさの確認の代わりにはなりません。

- ffprobe の長さ（6.1秒）と形式が、時間のJSON（`audio_seconds: 6.1`、`sample_rate: 48000`、`channels: 1`）と一致する。
- 区間は「本日はお集まりいただき、ありがとうございます。」が 0.00〜3.04秒、「発表の時間は十五分です。」が 3.54〜6.10秒で、間が 0.5秒ある。
- 音量はピーク約 -5.2 dBFS、RMS 約 -21.9 dBFS で、無音や音割れではない。

## まだ聞いていない範囲

全体（2文とも）。読み、抑揚、声の似かた、文の間の自然さは未確認です。

## 試聴してほしい箇所

- 3.54〜6.10秒の「十五分」が「じゅうごふん」と読まれているか（数字の読み）。
- 0.00〜3.04秒の「本日は」が「ほんじつは」、「お集まり」が「おあつまり」と読まれているか。
- 3.04〜3.54秒の間が、発表の冒頭として自然な長さに聞こえるか。

読み間違いがあれば、原稿の表記をかなに直して作り直します。

使い終わったため、エンジンのサーバーは `server stop` で止め、`server status` ですべて not running になっていることを確かめました。WAV は公開物に含めていません。

伏せ字: 声の名前（人名）を `<個人名>` に置き換えました。
