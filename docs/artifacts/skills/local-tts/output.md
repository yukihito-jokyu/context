## 合成までの経過

1. `server status`、`doctor`、`engine list`、`voice list`で状態を確かめた。Qwen3-TTSは`ready`で、既定のエンジン。既定の声`<個人名>`はQwen3-TTSのプロファイルを作り終えていた。Qwen3-TTSとOmniVoiceのサーバーは、この実行の前から別に起動されていた（`started elsewhere`）。
2. 2文を1文ずつ`<s>`に入れたSSML（`sample.ssml`）を書いた。数字は「十五分」と漢数字のままで、英字や記号はない。
3. `plan`で区切りを確かめた（`plan.txt`）。発話2つ、警告なし。
4. `speak sample.ssml --output sample.wav --engine qwen3-tts`で合成した。起動済みのサーバーを使い、生成にかかった時間は38.5秒（1文目22.6秒、2文目15.8秒）。音声の長さに対して約7.6倍だった。
