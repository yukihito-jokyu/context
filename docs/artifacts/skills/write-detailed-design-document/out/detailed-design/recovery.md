# 障害と再起動

[入口に戻る](README.md)

停止した場所ごとに確定した内容と残る情報を分け、再開と再試行の条件を定義する。

## recovery

<a id="RC001"></a>
### RC001

| 項目 | 内容 |
| --- | --- |
| 停止した場所 | 備品更新前、更新後・受付挿入前、返却後・状態確定前などCOMMIT前で停止する。 |
| 確定済みの内容 | 当該保存単位の変更は確定していない。ROLLBACK完了を確認できない間は未確認とする。 |
| 残る情報 | DB回復後は旧残数・旧予約状態・旧受付結果だけが残る。新規作成に欠番があっても予約はない。 |
| 再起動と再開 | DB回復を待ちIF003で受付結果を読む。監視はIF005へ進む前に候補を再読取りする。 |
| 再試行の条件 | 更新を自動再送しない。確定したロールバック応答を受信した場合だけ、利用者が明示した同じ内容の再操作を許可する。 |
| 呼出し元と画面の結果 | 確認済みrollbackはreadyへ戻る。応答がない画面はunknownであり、not_recordedだけでは確定失敗としない。 |
| 確認条件 | [C010](verification.md#C010)<br>[C012](verification.md#C012) |

<a id="RC002"></a>
### RC002

| 項目 | 内容 |
| --- | --- |
| 停止した場所 | COMMIT後・HTTP応答前、応答送信中、ブラウザ受信前で接続またはプロセスが停止する。 |
| 確定済みの内容 | 予約・数量変更・受付結果は同時に確定している。監視では予約状態と返却が同時に確定している。 |
| 残る情報 | T003に不変record、T001/T002に確定済み値が残る。画面への到達の証拠はない。 |
| 再起動と再開 | 画面は保存済み識別子でIF003だけを呼ぶ。予約がcancelled・expiredでも本人の結果読取りを許可する。 |
| 再試行の条件 | GETの再照会は許可する。元の作成・取消を自動再実行しない。外部実行基盤への作用はないため外部送信の回復は非該当とする。 |
| 呼出し元と画面の結果 | foundなら確定recordを表示する。操作時の残数・状態と現在値は別欄とし、過去の成立を現在の期限切れで拒否にしない。 |
| 確認条件 | [C011](verification.md#C011)<br>[C014](verification.md#C014) |

<a id="RC003"></a>
### RC003

| 項目 | 内容 |
| --- | --- |
| 停止した場所 | 同時再送のT003挿入衝突、COMMIT結果不明、照会時の保存側停止で止まる。 |
| 確定済みの内容 | 衝突の敗者は全変更をROLLBACKし勝者だけが確定する。COMMIT確認不能では確定の有無を断定しない。 |
| 残る情報 | 確定すれば一つの受付結果が残る。未確定の途中受付を永続化しない。 |
| 再起動と再開 | 衝突後は新しい読取りで勝者を照合する。DB読取り不能ならunknownを保ち、回復後にIF003を使う。 |
| 再試行の条件 | 同じ内容の照会だけを自動再実行可能とする。更新の内部トランザクションを勝手に再試行して後の在庫で判定し直さない。 |
| 呼出し元と画面の結果 | foundは終端結果、KEY_CONFLICTは内容衝突、not_recordedはまだ未確認、UNAVAILABLEは照会不能として区別する。 |
| 確認条件 | [C004](verification.md#C004)<br>[C005](verification.md#C005)<br>[C012](verification.md#C012) |

<a id="RC004"></a>
### RC004

| 項目 | 内容 |
| --- | --- |
| 停止した場所 | 監視の候補取得後、返却COMMIT前後、次の走査前に停止する。 |
| 確定済みの内容 | COMMIT前は返却なし、COMMIT後はexpiredと数量返却が確定する。確認不能ではST003だけをunknownとする。 |
| 残る情報 | 候補一覧はメモリ上で失われるが、期限とactive・終端状態はDBに残る。監視の実行枠やリースは設けない。 |
| 再起動と再開 | TR015でreadyに戻る前に保存側回復を待ち、activeかつ期限到来の候補を再走査する。終端ならno_changeとする。 |
| 再試行の条件 | 再走査後の条件付き期限処理を許可する。過去の加算SQLの再送は行わない。複数監視でもP002で一方だけが更新する。 |
| 呼出し元と画面の結果 | 次の現在値取得で返却後残数とexpiredを示す。停止中は期限到来・返却待ちの表示を許し、取消は保存側で期限を再検査する。 |
| 確認条件 | [C008](verification.md#C008)<br>[C009](verification.md#C009)<br>[C013](verification.md#C013)<br>[C016](verification.md#C016) |
