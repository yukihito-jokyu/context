## 原本と移動後の確認

`validation.json`に、元の文書検査、別の一時保存先へのrenderとcheckの終了値・出力、元成果物のSHA-256不変を記録した。原本の出典リンクは実行時の一時作業場所を指すが、必要な引用は本文にもある。移動後は同梱docsと台帳から再生成できる。

既存のNode.js、Mermaid CLIとブラウザーがある環境で、取得したスキルの場所を`<skill>`として次を実行する。

```sh
python3 <skill>/scripts/design.py render --root . --dir deliverables/reservation-design
python3 <skill>/scripts/design.py check --root . --dir deliverables/reservation-design
python3 <skill>/scripts/design.py sheets --root . --dir deliverables/reservation-design
```

PNGの表示確認も行う。追加パッケージは自動取得しない。ZIPには入力・出力・図・確認記録を含め、ZIP自身と、それをハッシュ登録するexecution.jsonは別に置く。
