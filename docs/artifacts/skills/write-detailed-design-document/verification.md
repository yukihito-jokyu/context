機械で取得した件数、実行イベント、再生成コマンドの終了値はvalidation.jsonに保存した。全成果物と実行したスキルの一覧・ハッシュはexecution.jsonにある。

## 同梱物とリンク

out/detailed-design内の11ファイルは今回生成した原本である。input.mdは実際に渡した依頼、docs内の2ファイルは入力資料、output.mdは実行担当の最終返答である。生成物にある引用リンクと最終返答の入口リンクは、実行時の一時作業場所を指す絶対パスのまま保存している。ダウンロード先に合わせて原本を書き換えてはいない。

移動先で引用リンクを利用する場合は、ZIPを展開し、入力資料と台帳を含むコピーを再生成する。スキルの場所を実際の導入先へ置き換え、展開先をカレントディレクトリにして実行する。

```sh
DETAIL_SKILL_DIR=/path/to/write-detailed-design-document
python3 "$DETAIL_SKILL_DIR/scripts/design.py" render --root . --dir out/detailed-design --source '["docs/requirement.md","docs/basic-design.md"]'
python3 "$DETAIL_SKILL_DIR/scripts/design.py" check --root . --dir out/detailed-design --source '["docs/requirement.md","docs/basic-design.md"]'
```

この方法で移動先の入力資料へのリンクを作り直せる。生成されたMarkdownやHTMLを直接編集すると、その後の検査で不一致として扱われる。
