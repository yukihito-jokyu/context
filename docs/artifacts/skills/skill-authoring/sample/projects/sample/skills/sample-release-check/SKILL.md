# sample-release-check

sampleプロジェクトのリリース前に、指定された変更差分と検証記録を読み取り、人間が公開可否を判断するための短い整理を作る。

## 対象と範囲

- sampleプロジェクト専用。
- 読み取りだけを行う。コミット、タグ、push、公開は行わない。
- 公開可否は人間が判断する。

## 手順

1. 指定された変更差分と検証記録の場所を確認する。指定が足りなければ不足を伝えて確認する。
2. 差分から利用者に影響する変更を要約し、根拠となるファイルを示す。
3. 検証記録を読み、成功・失敗・未実施を区別する。記録のない確認を成功として扱わない。
4. 残課題を列挙する。公開可否の判断は示さず、人間に残す。

## 出力

- 対象の差分と検証記録
- 利用者への変更と根拠
- 確認結果（成功・失敗・未実施）
- 残課題

秘密情報は引用せず、必要な場合は伏せた要約だけを書く。
