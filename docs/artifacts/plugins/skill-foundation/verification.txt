repository absolute path → <repository>
temporary workdir → <workdir>
user home absolute path → <user-home>
system temporary path → <system-temp>

Reproduction:
Run this script with --repo-root pointing to the complete current repository and a new --workdir. The plugin-owned tests are imported from that repository; copying a test file alone is insufficient.
